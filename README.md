# F1 Vehicle Performance Model

An engineering study and Python-based simulation of an F1-style vehicle.

## Project Goal

The goal of this project is to develop a vehicle performance model from first principles.

The project will progressively cover:

- Engine performance
- Powertrain
- Drivetrain
- Tyres
- Vehicle dynamics
- Aerodynamics
- Energy management
- Lap-time simulation

## Methodology

Each topic will be studied through:

1. Engineering theory
2. Technical vocabulary
3. Mathematical modelling
4. Python implementation
5. Visualization
6. Validation
